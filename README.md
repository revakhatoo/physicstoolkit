# PHYSICS TOOLKIT

A university-level physics error analysis and graph calculator designed to help students make physics project reports with ease. 

🚀 **[Try the Live App Here](https://physicstoolkit.streamlit.app)**

## Features
* **Reading Based:** Calculate mean, standard deviation, and standard error from raw measurements.
* **Graphical Analysis:** Generate lines of best fit (generating graphs)
* **Formula Based:** Perform linear error propagation and 10,000-iteration Monte Carlo simulations for formulas.

## Built With
* Streamlit
* SymPy
* Matplotlib
* NumPy
